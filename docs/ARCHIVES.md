# Archives du projet

## Tentative C#/WPF (.exe)

La version historique en C#/.NET, avec son interface WPF et les workflows Velopack, est conservée dans la branche [archive/dotnet-wpf](https://github.com/77Romain77/ClickFlow-AutoClicker/tree/archive/dotnet-wpf).

La release [v0.1.0](https://github.com/77Romain77/ClickFlow-AutoClicker/releases/tag/v0.1.0) reste accessible comme archive historique. **Elle n'est pas la version actuelle recommandée** et son exécutable peut être bloqué par les protections Windows.

## Prototypes AutoHotkey

Les branches `experimental/autohotkey` et `experimental/webview2` ainsi que les releases préliminaires v0.3.x conservent les étapes de développement antérieures.

Les scripts de diagnostic et anciens workflows de tests ont été retirés de `main` sans effacer leur historique Git.

## Version actuelle

Utiliser la version stable [v1.10.0](https://github.com/77Romain77/ClickFlow-AutoClicker/releases/tag/v1.10.0), au format `.ahk` unique. Le workflow ne compile aucun `.exe` ClickFlow.

La dernière version de développement de la série 1.9, [v1.9.33](https://github.com/77Romain77/ClickFlow-AutoClicker/releases/tag/v1.9.33), reste accessible comme version antérieure pour comparaison ou retour arrière. Les releases précédentes ne sont pas supprimées.
