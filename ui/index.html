À propos de ClickFlow.

Gère les raccourcis, le stockage et la désinstallation de l'application.

Application Windows

ClickFlow, prêt à être lancé depuis Windows

ClickFlow utilise AutoHotkey v2 et WebView2 pour ouvrir une fenêtre indépendante, avec sauvegarde des profils et des réglages.

Le fichier unique peut créer des raccourcis avec notre icône dans le menu Démarrer et sur ton bureau. Aucun exécutable ClickFlow n'est nécessaire.

Stockage et désinstallation

Ouvre les dossiers de ClickFlow ou désinstalle le programme depuis cette fenêtre.

Une confirmation sera demandée. L'effacement complet nécessitera aussi de saisir SUPPRIMER. Le fichier .ahk téléchargé ailleurs sur le disque n'est pas effacé automatiquement.
